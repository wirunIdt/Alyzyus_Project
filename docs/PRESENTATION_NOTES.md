# บทพูดประกอบสไลด์ Alyzyus

Mr. Wirun Earmvorakul ระยะเวลาประมาณ 5 ถึง 7 นาที

## สไลด์ 1

แนะนำตัวและโครงการประมาณ 30 วินาที ผมเสนอแนวคิดและกำหนดความต้องการของ Alyzyus โดยพัฒนาต้นแบบร่วมกับเครื่องมือ AI โครงการนี้ใช้ร้านค้าออนไลน์เป็นโจทย์เพื่อศึกษาความถูกต้องของข้อมูล สิทธิ์ผู้ใช้ และการอธิบายกระบวนการด้วย 3D ภาพประกอบแบรนด์สร้างด้วย AI ดู ASSETS.md

## สไลด์ 2

อธิบายโจทย์ 35 วินาที ระบบเดิมเป็นฟอร์มรับคำสั่งซื้อ โครงการขยายให้หน้าร้านและหลังบ้านใช้ข้อมูลชุดเดียวกัน การแบ่งผู้ใช้สองกลุ่มทำให้ต้องออกแบบสิทธิ์และการตรวจข้อมูลชัดเจน ไม่อ้างว่ามีผู้ใช้หรือรายได้จริง

## สไลด์ 3

เปิดหน้าเว็บจริง https://alyzyus.vercel.app และสลับภาษาและธีมใช้เวลา 45 วินาที ภาพนี้เป็นหน้าร้านที่ Deploy จริง สินค้าฐานข้อมูลยังเป็น draft จึงไม่แสดงสินค้าพร้อมขาย การทดลองถุงสินค้าควรใช้โหมดตัวอย่างในเครื่องหรือฐานข้อมูลทดสอบ ที่มา templates และ public/static ของ repository

## สไลด์ 4

อธิบาย 45 วินาที Flask ตอบหน้า HTML และ JSON API ส่วน Supabase จัดการบัญชีและข้อมูล ตัวเว็บใช้ JavaScript ปกติ Three.js เปิดเมื่อผู้ใช้เข้าดูฉากเท่านั้น RLS ช่วยจำกัดการเข้าถึงระดับฐานข้อมูล โค้ด server/__init__.py auth.py api.py database.py และ migrations อธิบายได้จริง

## สไลด์ 5

45 วินาที เปิด function create_order ใน SQL หากผู้ประเมินต้องการดูโค้ด อธิบายตัวอย่างลูกค้าแก้ราคาในเบราว์เซอร์และการกดปุ่มซ้ำ สต็อกและคำสั่งซื้อควรสำเร็จร่วมกัน Stripe webhook มีโค้ดรองรับและทดสอบด้วยข้อมูลจำลอง แต่บัญชีร้านยังไม่ได้เปิดรับเงินจริง ข้อเท็จจริงอยู่ tests/database.test.mjs และ tests/test_backend.py

## สไลด์ 6

35 วินาที เปิด /simulation?mode=product อธิบายป้าย DEMO และหมุนฉาก การเปิด order=<UUID> อ่านออเดอร์ที่บัญชีมีสิทธิ์เท่านั้น การเคลื่อนไหวไม่เปลี่ยนสถานะคำสั่งซื้อและไม่ใช่ตำแหน่งจริงของพัสดุ ที่มาภาพจากเว็บจริง public/static/queue3d.html

## สไลด์ 7

50 วินาที เปิด /simulation ทดลองเพิ่มอัตราคนเข้าเป็น 20 และเพิ่มเจ้าหน้าที่เอกสารจาก 1 เป็น 3 หากเกิดคิวอาจใช้ความเร็ว 5 เท่า ค่าทั้งหมดเป็นแบบจำลองไม่ใช่ข้อมูลสำนักงานจริง หนึ่งการทดลองไม่เพียงพอสรุปเชิงสถิติ แบบจำลองไม่เขียนข้อมูลร้าน ภาพนี้จากฉากที่ Deploy จริง

## สไลด์ 8

35 วินาที แสดงคำสั่ง python -B -m unittest discover -s tests -p test_*.py และ npm --prefix tests test รุ่น 15 ตุลาคม 2026 มี Python 38 และ Node 15 กรณี โดย Node รวม database/audit 2 suite, PWA 5 และ queue 8 กรณี อย่าอ้างว่าปราศจากข้อผิดพลาด Security advisor ไม่พบปัญหา RLS ของ Log แต่ยังมีคำเตือน Leaked Password Protection ที่เจ้าของบัญชีต้องตรวจตั้งค่า ดู docs/ACTIVITY_LOGS.md การตรวจนี้ไม่ใช่การตรวจเจาะระบบเต็มรูปแบบ

## สไลด์ 9

35 วินาที อธิบายว่าจำกัดจำนวนที่วาดแต่คำนวณจำนวนคนในคิวครบทั้งหมด ไม่รับประกันทุกเครื่องลื่นเท่ากันและยังไม่มี benchmark ภาคสนาม บัญชีรับเงินออนไลน์ยังไม่ได้ตั้งค่า สินค้า draft จะไม่ขาย จึงเป็นต้นแบบที่ Deploy และเชื่อมข้อมูลจริงแล้วแต่ยังต้องตั้งข้อมูลธุรกิจ

## สไลด์ 10

ปิดการนำเสนอ 30 วินาที โครงการใช้ข้อกำหนดที่ผมเสนอและพัฒนาร่วมกับ AI ผมควรเตรียมอธิบายและแก้โค้ดตัวอย่างด้วยความเข้าใจของตนเอง ไม่อ้างว่าเขียนทุกบรรทัดโดยไม่มีเครื่องมือช่วย Repository เป็น Private ผู้ประเมินต้องได้รับสิทธิ์จากเจ้าของก่อน เปิดเว็บจริงได้ทันที เอกสารนี้ไม่รับรองเกณฑ์การรับเข้าของมหาวิทยาลัย
