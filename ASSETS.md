# Alyzyus assets

The original hero was generated using the built-in Imagegen tool for this project and archived at `legacy/assets/alyzyus-hero.png`. The web uses the same image encoded as `public/static/images/alyzyus-hero.webp` (1536 × 1024, approximately 70 KB). No Ferrari branding, assets, or page layout were copied.

Generation prompt:

> Use case: product-mockup. Asset: wide cinematic hero photograph for premium multi-category online boutique Alyzyus. Create a refined editorial product still life on an architectural matte lavender plinth against a warm light grey studio background: sculptural ivory over-ear headphones are the main subject, accompanied by a small brushed aluminium portable speaker, a cream sculptural table lamp and folded soft taupe canvas tote. Quiet luxury everyday goods, no brand logos, no text, no letters, no watermark, no UI. Products predominantly occupy RIGHT two-thirds, LEFT third soft empty background usable for copy. Directional afternoon sun from top left produces long graphic shadows, subtle tactile materials, restrained lavender and warm white palette. Premium real product photography, visually convincing objects, artistic asymmetrical composition, landscape 3:2.

Demo catalog and collection photos use Unsplash image URLs recorded in `data/demo-products.json` and `templates/index.html`. These are illustrative images, not verified photographs/specifications of actual stock. Replace demo product images, text, prices and quantities with the merchant's actual inventory before activating products.

Fonts: DM Sans, Noto Sans Thai and Noto Sans SC, loaded with `font-display: swap` via Google Fonts. System sans-serif remains the fallback. The interface uses small inline SVG icons and a text wordmark.
